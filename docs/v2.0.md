# ResponsiveLab v2.0

## The Multi-Device Upgrade
Version 2.0 transformed the tool from a basic single-iframe previewer into a powerful, professional workspace. The focus was on expanding capabilities, improving the UI, and adding highly requested utility tools.

### Key Features Implemented:
- **Multi-Device Grid Engine**: Overhauled the core JS logic to allow multiple devices to be tested side-by-side simultaneously. Each device calculates its own CSS transform scale so it fits neatly within the vertical height of the screen.
- **Realistic CSS Device Frames**: Replaced standard square borders with beautiful CSS mockups (e.g., iPhone notches, MacBook bottom bezels, rounded corners) that load instantly with zero image assets.
- **Light / Dark Mode**: Integrated a theme toggle in the top bar with full CSS variable support. Themes are saved to `localStorage`.
- **QR Code Generator**: Added a modal integrated with the `goqr.me/api.qrserver.com` API. Users can instantly generate a QR code of their testing URL to scan with a physical smartphone.
- **Rulers & Guidelines**: Added professional measuring rulers to the top and left edges of the preview area using pure CSS backgrounds.
- **Smart URL Input**: Added regex logic to detect and auto-format naked domains (e.g., typing `google.com` seamlessly resolves to `https://google.com`).
- **Loading Animations**: Added a dimming overlay and spinner animation that masks the iframes while they fetch cross-origin content through the proxy.
- **Mobile Responsive Layout**: Completely redesigned the layout for small screens. The sidebar was converted into a slide-in drawer activated by a hamburger menu, and the header elements wrap elegantly.
- **Custom Logo & Branding**: Replaced placeholder SVGs with custom PNG branding (`Logo.png` and `fav.png`).
